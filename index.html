Evaluasi Pengalaman: Kartu Fisik vs QR Code

Pilih skala: 1 = Sangat Tidak Setuju (STS), 2 = Tidak Setuju (TS), 3 = Setuju (S), 4 = Sangat Setuju (SS)

1. Pemindaian QR Code SIAP PAI jauh lebih efisien dan mengurai antrean panjang dibandingkan pembagian/cap kartu fisik setelah sholat.

2. Saya merasa lebih tenang dan tidak cemas kehilangan kartu, kartu basah saat wudhu, atau tertinggal di rumah/laci meja.

3. Sistem QR Code SIAP PAI meminimalisasi praktik titip presensi / kecurangan manipulasi kartu yang dulu sering terjadi.

Kemudahan Layanan Jika QR Code / ID Card Ketinggalan

4. Ketika kartu fisik/ID Card QR Code tertinggal di rumah/kelas, aplikasi SIAP PAI memberikan kemudahan solusi (misalnya: pencarian nama manual oleh petugas/guru, scan via galeri foto HP, atau input nomor absen) tanpa perlu panik atau dihukum.

Privasi Udzur Syar'i (Haid / Berhalangan) Khusus Siswi

5. Sistem SIAP PAI lebih menjaga privasi, kehormatan, dan tidak menimbulkan praduga negatif saat siswi sedang berhalangan/haid dibanding pelaporan kartu manual di depan umum.
